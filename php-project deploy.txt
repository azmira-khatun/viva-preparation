✅ PHP Project Deploy করার ধাপসমূহ
🔹 1. Hosting & Domain প্রস্তুত করা
প্রথমে লাগবে:

Web Hosting (cPanel / DirectAdmin ইত্যাদি)

Domain name

👉 সাধারণত hosting নিলে সাথে cPanel পাওয়া যায়।

🔹 2. cPanel এ Login করুন
আপনার hosting provider থেকে পাওয়া
cPanel URL, username, password দিয়ে login করুন

🔹 3. Project Files Upload করুন
cPanel → File Manager

public_html ফোল্ডারে যান

আপনার PHP project:

.zip হলে → Upload → Extract

না হলে → সব ফাইল copy করে দিন

📁 সাধারণত এই ফাইলগুলো থাকবে:

index.php
config.php
assets/
css/
js/
🔹 4. Database তৈরি করুন (MySQL)
cPanel → MySQL Databases

Create করুন:

Database name

Database user

Password

User কে Database-এ ALL PRIVILEGES দিন ✔️

🔹 5. Database Import করুন
cPanel → phpMyAdmin

আপনার database select করুন

Import tab → .sql file upload করুন

Go ক্লিক করুন

🔹 6. config.php / db.php আপডেট করুন
আপনার project-এ যেখান থেকে DB connect হয় সেখানে দিন:

$host = "localhost";
$user = "database_user";
$pass = "database_password";
$db   = "database_name";

$conn = mysqli_connect($host, $user, $pass, $db);
⚠️ Localhost এর credentials ব্যবহার করবেন না

🔹 7. Base URL ঠিক করুন (যদি থাকে)
যদি project-এ base URL থাকে:

define("BASE_URL", "https://yourdomain.com/");
🔹 8. File Permission ঠিক করুন
Folder → 755

File → 644

(বিশেষ করে uploads/ ফোল্ডার writable হতে হবে)

🔹 9. Error Check করুন
সাময়িকভাবে error দেখাতে চাইলে:

ini_set('display_errors', 1);
error_reporting(E_ALL);
Deploy শেষ হলে আবার বন্ধ করে দিন 🔐

🔹 10. Browser এ Test করুন
👉 যান:

https://yourdomain.com
সব ঠিক থাকলে project live 🎉

⚠️ Common সমস্যা ও সমাধান
সমস্যা	কারণ
Blank page	PHP error / DB connect হয়নি
500 Error	permission বা .htaccess issue
DB error	ভুল username/password
CSS load না	ভুল path
