✅ PHP Project Deploy করার ধাপসমূহ
🔹 1. Hosting & Domain প্রস্তুত করা
প্রথমে লাগবে:

Web Hosting (cPanel / DirectAdmin ইত্যাদি)

Domain name

👉 সাধারণত hosting নিলে সাথে cPanel পাওয়া যায়।

🔹 2. cPanel এ Login করুন
আপনার hosting provider থেকে পাওয়া
cPanel URL, username, password দিয়ে login করুন

🔹 3. Project Files Upload করুন
cPanel → File Manager

public_html ফোল্ডারে যান

আপনার PHP project:

.zip হলে → Upload → Extract

না হলে → সব ফাইল copy করে দিন

📁 সাধারণত এই ফাইলগুলো থাকবে:

index.php
config.php
assets/
css/
js/
🔹 4. Database তৈরি করুন (MySQL)
cPanel → MySQL Databases

Create করুন:

Database name

Database user

Password

User কে Database-এ ALL PRIVILEGES দিন ✔️

🔹 5. Database Import করুন
cPanel → phpMyAdmin

আপনার database select করুন

Import tab → .sql file upload করুন

Go ক্লিক করুন

🔹 6. config.php / db.php আপডেট করুন
আপনার project-এ যেখান থেকে DB connect হয় সেখানে দিন:

$host = "localhost";
$user = "database_user";
$pass = "database_password";
$db   = "database_name";

$conn = mysqli_connect($host, $user, $pass, $db);
⚠️ Localhost এর credentials ব্যবহার করবেন না

🔹 7. Base URL ঠিক করুন (যদি থাকে)
যদি project-এ base URL থাকে:

define("BASE_URL", "https://yourdomain.com/");
🔹 8. File Permission ঠিক করুন
Folder → 755

File → 644

(বিশেষ করে uploads/ ফোল্ডার writable হতে হবে)

🔹 9. Error Check করুন
সাময়িকভাবে error দেখাতে চাইলে:

ini_set('display_errors', 1);
error_reporting(E_ALL);
Deploy শেষ হলে আবার বন্ধ করে দিন 🔐

🔹 10. Browser এ Test করুন
👉 যান:

https://yourdomain.com
সব ঠিক থাকলে project live 🎉

⚠️ Common সমস্যা ও সমাধান
সমস্যা	কারণ
Blank page	PHP error / DB connect হয়নি
500 Error	permission বা .htaccess issue
DB error	ভুল username/password
CSS load না	ভুল path

✔️ Error আসছে কিনা

🌍 PHP Project Deploy (Beginner Step by Step)
👉 ধরি আপনার Core PHP project আছে
👉 ধরি আপনার কাছে Hosting + cPanel আছে

🧩 STEP 1: cPanel এ Login করুন
1️⃣ Hosting provider থেকে দেওয়া cPanel link খুলুন
2️⃣ Username & Password দিন
3️⃣ Login ক্লিক করুন

✔️ এখন আপনি cPanel Dashboard দেখবেন

🧩 STEP 2: Project Upload করুন
1️⃣ cPanel → File Manager
2️⃣ public_html ফোল্ডারে ক্লিক করুন
3️⃣ উপরে Upload ক্লিক করুন
4️⃣ আপনার project এর ZIP file select করুন
5️⃣ Upload শেষ হলে ← Back যান
6️⃣ ZIP file এর উপর Right click → Extract

✔️ এখন আপনার project ফাইল দেখা যাবে

🧩 STEP 3: Database বানান
1️⃣ cPanel → MySQL Databases
2️⃣ Create New Database

Database Name লিখুন → Create
3️⃣ নিচে MySQL Users

Username দিন

Password দিন

Create User
4️⃣ Add User To Database

User select

Database select

✔️ ALL PRIVILEGES দিন

Make Changes

✔️ Database ready ✅

✍️ এই তিনটা লিখে রাখুন:

Database Name
Username
Password
🧩 STEP 4: Database Import করুন
1️⃣ cPanel → phpMyAdmin
2️⃣ Left side থেকে আপনার Database নাম ক্লিক করুন
3️⃣ উপরে Import ট্যাব
4️⃣ Choose File → .sql file select
5️⃣ Go ক্লিক করুন

✔️ Database data চলে আসবে

🧩 STEP 5: Database Connection ঠিক করুন
1️⃣ File Manager → project folder
2️⃣ খুঁজুন:

config.php
db.php
connection.php
3️⃣ File এ ক্লিক → Edit

এভাবে লিখুন:

$host = "localhost";
$user = "your_db_user";
$pass = "your_db_password";
$db   = "your_db_name";

$conn = mysqli_connect($host, $user, $pass, $db);
✔️ Save করুন

🧩 STEP 6: Website খুলে দেখুন
Browser এ লিখুন:

https://yourdomain.com
🎉 যদি site খুলে → success

error_reporting(E_ALL);

1️⃣ File Manager এ folder select করুন
